# Hawkins

**一个《怪奇物语》的互动地理时空地图** — 霍金斯小镇地图上，随时间轴漫游关键时刻。

| 阶段 | 内容 | 状态 |
|---|---|---|
| **阶段一** | 项目脚手架 + CI/CD + 数据类型 | ✅ 完成 |
| **阶段二** | 霍金斯 SVG 地图 + 地点热点 + InfoCard | ✅ 完成 |
| **阶段三** | 时间轴引擎 + 时刻切换动效 | ✅ 完成 |
| **阶段四** | 氛围图层 + 自动播放 + Upside Down 开场 | ✅ 完成 |
| **阶段五** | S2 数据验证 + CONTRIBUTING.md + 社区准备 | 🔲 待开始 |

v1 目标：第 1 季 ≥ 20 个完整时刻，≥ 8 个核心人物，所有主要霍金斯地点可点击。
